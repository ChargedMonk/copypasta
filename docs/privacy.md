# Rip Multi Paste Privacy Policy

Last updated: 2026-04-29

Rip Multi Paste is a local-only Windows clipboard history app.

## Data Collection

Rip Multi Paste does not collect personal data, analytics, telemetry, or usage data.

## Clipboard Data

Rip Multi Paste watches the Windows clipboard so it can save recent clipboard items for later search and paste. Clipboard history is stored only on your PC in the app's local data folder. Clipboard data is not uploaded, sold, shared, or sent to any server.

## Internet Access

Rip Multi Paste does not require an account and does not connect to the internet.

## User Controls

You can pause clipboard capture, clear clipboard history, or exit the app from the tray menu.
