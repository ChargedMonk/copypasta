# Rip Multi Paste Store Listing

## Short Description

Fast local clipboard history, search, and multi-paste for Windows.

## Full Description

Rip Multi Paste is a lightweight Windows clipboard history tool built for fast, local-only copying and pasting. It runs quietly in the background, saves a larger local clipboard history than the built-in Windows clipboard history, and lets you quickly find and paste previous items with a global shortcut.

Your clipboard data stays on your device. Rip Multi Paste does not require an account, does not connect to the internet, and does not sell, upload, or share your data.

Features:

- Fast clipboard history picker
- Search across saved clipboard items
- Stores more history than Windows clipboard history's small recent-item limit
- Global keyboard shortcuts
- Multi-format clipboard support for text, rich text, images, HTML, and file drops where supported
- Tray controls to pause capture, clear history, open settings, or exit
- Local-only storage on your PC

## Notes For Certification

Rip Multi Paste captures clipboard updates only on the user's device and stores clipboard history locally under the user's local app data directory. It does not use network APIs, analytics, accounts, or cloud sync. Users can pause capture, clear history, and exit from the tray menu.
